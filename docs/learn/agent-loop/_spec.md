## 1. 目标

这份教程面向正在学习 mini 版 DSH 的开发者，详细讲清楚 Agent 句柄、
Agent Loop 核心循环、Cordis 插件封装以及对应测试如何协同工作。
正文采用中文，并对新增代码进行逐行或逐代码块解释，让没有 Agent
开发经验的读者也能独立理解一次完整的“模型 → 工具 → 模型”运行过程。

**明确边界（Agent Loop 讲解范围）：**

| 做 | 不做 |
| --- | --- |
| 逐行讲解 `agent-runtime.ts` | 不接入真实模型 API |
| 逐行讲解 `agent-loop-runtime.ts` | 不扩展新的业务工具 |
| 讲解 `agents.ts` 与 `agent-loop.ts` 插件 | 不把教程写成 API 参考手册 |
| 讲解 `core.test.ts` 中 4 个新增测试 | 不修改现有 Agent Loop 业务行为 |
| 串联 Session、Prompt、Tool、LLM 依赖 | 不讨论前端 UI 实现 |
| 解释多工具取消时的日志配对问题 | 不引入当前项目没有使用的框架 |

## 2. 受众定位

- **🐤 A 类小白**：了解 TypeScript 基础语法，但没有写过 Agent Loop，
  不熟悉依赖注入、事件日志、工具调用配对和 AbortSignal。
- **🦾 B 类后端**：熟悉常规服务端分层、依赖注入和异步编程，
  希望在 60-90 分钟内理解本项目 Agent Loop 的职责边界和数据流。
- **⚡ C 类老手**：使用过其他 Agent 框架，希望快速定位本项目在
  无步数上限、事件投影和取消一致性方面的设计选择。

不预设读者已经理解 Agent、Agent Loop、tool call、disposer、
content block 或事件投影。每个术语都要先用中文解释，再结合源码说明。

## 7. 测试讲解范围

教程必须逐步讲解以下四个测试：

1. `Agent loop completes a model -> tool -> model turn`
2. `Agent loop has no 12-step cap and finishes after 20 tool calls`
3. `Agent loop streams reasoning, content, tool-call, and tool-result chunks`
4. `Cancelling a multi-tool turn still records a result for every tool_call`

每个测试均说明：

- Arrange：准备了哪些 Runtime 和 mock
- Act：调用了哪个公开入口
- Assert：断言保护了什么行为
- 如果实现错误，该测试会如何失败
